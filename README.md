# Overview

CoreDataCombineApp is a SwiftUI-based iOS application that fetches data from an API using Combine, stores it in Core Data, and displays it in a SwiftUI view. The app follows the MVVM architecture to ensure clean code separation and scalability.

# Features

- Fetches data from https://jsonplaceholder.typicode.com/posts using Combine.

- Saves and retrieves data persistently using Core Data.

- Displays posts in a SwiftUI List.

- Implements MVVM architecture for better maintainability.

# Technologies Used

- Swift 5

- SwiftUI

- Combine

- Core Data

- MVVM Architecture
